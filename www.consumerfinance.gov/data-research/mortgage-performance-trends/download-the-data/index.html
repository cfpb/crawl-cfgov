Download the data

Explore the data that power our charts and maps with the software of your choice.

The files contain data aggregated by state, metro and non-metro areas, and county. We include individual metro areas, non-metro areas, and counties if there are at least 1,000 mortgages in our sample for that geography.

The most recent data

We recommend using the most recent data, which include the full time series and all revisions. These data cover January 2008–December 2025. Since this webpage’s December 2023 update, we use Connecticut’s new FIPS codes that changed in 2022 to nine county-equivalent boundaries.
